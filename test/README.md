### Mô tả
Lớp Student quản lý thông tin sinh viên, gồm:
- Mã sinh viên.
- Họ và tên.
- Email.

### Chức năng
- Khởi tạo đối tượng sinh viên.
- Đọc thông tin qua getter.
- Cập nhật họ tên và email.
- Hiển thị thông tin sinh viên.

### File thực hiện
- student.dart: khai báo lớp Student.
- main.dart: tạo đối tượng và chạy minh họa.

### Cách chạy
dart run main.dart
